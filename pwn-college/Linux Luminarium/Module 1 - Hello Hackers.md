A very basic intro with not much to be noted down. In general when you open the Terminal initially, it executes a command line "shell", which always look like of the form 

```console
hacker@dojo:~$
```

hacker - username of current user 
dojo - hostname of the machine
~ - users home path/home variable
$ - signifies not an admin, # means you're an admin

Apart from that some important commands are 

-) whoami - simply prints the username
-) echo - echoes something to the Terminal, takes in arguments
